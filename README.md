# Semplo — Enterprise HR & Payroll Management System

An enterprise-grade, multi-persona Human Resource Information System (HRIS) and statutory payroll operating system tailored for Kenyan labor laws (Kenya Employment Act, KRA iTax, NSSF Act 2013, SHIF, and Affordable Housing Levy).

---

## 🌟 Key Functional Pillars

- **Overview Dashboard & Real-Time Analytics**: Executive KPI cards, department allocations, live punch attendance trends, statutory payroll distributions, and quick navigation.
- **Employee Directory & Lifecycle Management**: 360° employee dossier, digital onboarding roadmaps, offboarding clearance checkpoints, document vault, and photo uploads.
- **Biometric Time & Attendance Terminal**: Real-time virtual punch clock (Clock In, Breaks, Clock Out), daily work minutes calculation, and multi-shift schedules.
- **Leave & Absence Governance**: Statutory Kenyan leave policies (Annual 21 days, Maternity 90 days, Paternity 14 days, Sick leave, Compassionate), real-time balance tracking, and manager approvals.
- **Kenyan Payroll Processing & Statutory Deductions**:
  - Progressive KRA PAYE tax bands with personal relief (KES 2,400/mo), SHIF insurance relief (15%), and Housing relief (15%).
  - NSSF Tier 1 (KES 420 max) and Tier 2 (KES 1,740 max) employer-matched contributions.
  - Social Health Insurance Fund (SHIF 2.75%) & Affordable Housing Levy (1.5% employee + 1.5% employer).
  - Net salary calculations, printable digital payslips, and KRA/NSSF/SHIF statutory remittance summaries.
- **Performance Appraisals & OKRs**: Multi-competency reviews, self-assessments, manager evaluations, and interactive 9-Box Talent Quadrant.
- **Recruitment ATS Pipeline**: Requisitions directory, candidate scorecards, hiring pipelines, and 1-click hire-to-onboarding conversion.
- **Employee Self-Service (ESS)**: Request hub for salary advances (up to 50% basic pay), digital expense claims, official verification letters, and asset requisitions.
- **Company Hub & Bulletins**: Pinned notices, statutory policies with digital signing, team celebrations, and immutable compliance audit trail.

## 🚀 Getting Started

### Local Development
```bash
# Clone the repository
git clone https://github.com/versalylabs/semplo-employee-hr-ms.git
cd semplo-employee-hr-ms

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build
```bash
# Compile and build production bundle
npm run build

# Preview production build
npm run preview
```
